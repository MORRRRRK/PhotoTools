# 3D LUT 预设说明

内置预设均由本项目代码生成的原创 `.cube` 文件，无版权争议：

- `none.cube`：无效果（恒等映射）
- `kodak_2383.cube`：柯达 2383 电影胶片近似
- `fuji_velvia.cube`：富士 Velvia 高饱和反转片近似
- `arri_logc.cube`：阿莱 LogC 风格
- `teal_orange.cube`：青橙电影色调
- `vintage_film.cube`：复古胶片
- `portra_400.cube`：柯达 Portra 400 人像近似
- `ektar_100.cube`：柯达 Ektar 100 风景近似
- `black_white.cube`：黑白电影
- `bleach_bypass.cube`：漂白旁路效果

支持用户导入自定义 `.cube` 文件，加载后可直接使用。
