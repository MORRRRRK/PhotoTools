 # PhotoTools — 摄影素材管理工具箱 需求文档

> 文档版本：V1.0（需求汇总）  
> 编制日期：2026-07-26  
> 对应代码：photo_tools_v1 / v2 / v2_backup

---

## 一、产品概述

### 1.1 产品定位
面向摄影爱好者的 Windows 桌面工具，解决摄影素材管理中的两大痛点：
1. 摄影过程中 JPG+RAW/PNG 双格式存储，筛选删除 JPG 后残留同名 RAW/PNG 导致素材库臃肿
2. 照片质量缺乏客观评价标准，难以快速判断保留价值

### 1.2 运行环境
- **操作系统**：Windows 10/11
- **运行环境**：Python 3.11+（自带或系统安装均可）
- **启动方式**：双击 run.bat（自动检测 Python）
- **打包方式**：PyInstaller → 单文件 exe

---

## 二、界面布局（整体）

### 2.1 窗口
- 默认尺寸：1250×800
- 最小尺寸：1000×650
- 三栏 Tab 布局：单一文件类型筛选 / 照片质量评估 / 设置
- 外观模式：system / light / dark 切换（设置中配置）
- 配置持久化：config.json 自动读写

### 2.2 启动
- 双击 run.bat → pythonw.exe 无命令行窗口启动
- 优先检测系统 python，其次用 Codex 自带 Python
- 找不到 Python 则提示下载

## 三、「单一文件类型筛选」Tab 需求

### 3.1 文件夹管理区（顶部）

#### 3.1.1 文件夹列表
- 使用树形表格（ttk.Treeview）展示
- **列定义**（3列）：
  | 列 | 说明 |
  |---|---|
  | ☐（复选框列） | 勾选/取消勾选，用于批量操作 |
  | 文件夹路径 | 显示文件夹完整路径 |
  | 文件数量 | 预留待填充（当前显示"-"） |
  | 添加时间 | 记录加入列表的时间 |
- **列间距手动调整**：所有列支持鼠标拖拽改变宽度（类似 Excel 列头拖拽）
- **居中排版**：列标题和数据行内容都居中对齐（anchor="center"）
- **复选框对齐**：全选复选框的勾选框与列表中的复选框列垂直对齐

#### 3.1.2 文件夹操作按钮
- **「+ 添加文件夹」**：弹出文件夹选择器，单选添加
- **「+ 批量添加」**：选择根目录，自动导入其所有直接子文件夹
- **「− 移除选中」**：删除列表中已勾选的文件夹（支持批量）

### 3.2 扫描控制区（中部）

#### 3.2.1 扫描按钮
- 「开始扫描」
- 扫描中显示：「扫描中...」文字 + 按钮禁用
- 扫描完成恢复

#### 3.2.2 进度条
- 实时显示扫描进度（已完成文件夹数 / 总数）

#### 3.2.3 状态文字
- 闲置：「就绪」
- 扫描中：「扫描 xxx 文件夹...」
- 完成：「扫描完成」
- 失败：「扫描失败」

#### 3.2.4 扫描逻辑
- **并行扫描**：ThreadPoolExecutor，默认 4 线程（可在设置中调整）
- **按文件夹单独扫描**：每个文件夹独立执行扫描任务
- **分组汇总结果**：扫描结果标注来源文件夹，汇总展示

### 3.3 结果展示区（下部，占大部分空间）

#### 3.3.1 全选
- 「全选」复选框位于结果列表正上方
- 与列表的复选框列垂直对齐
- 勾选/取消勾选全部结果行

#### 3.3.2 结果列表
- 使用树形表格（ttk.Treeview）展示
- **列定义**：
  | 列 | 说明 | 交互 |
  |---|---|---|
  | ☐（复选框列） | 勾选/取消 | 单击切换 |
  | 文件路径 | 显示文件名 | **单击打开预览文件** |
  | 类型 | 文件扩展名 | 纯展示 |
  | 大小 | 格式化文件大小 | 纯展示 |
  | 来源文件夹 | 文件所在文件夹 | **单击打开资源管理器定位** |
- **列间距手动调整**：所有列支持鼠标拖拽改变宽度
- **居中排版**：列标题和数据行内容都居中对齐

#### 3.3.3 数据刷新
- 每次扫描「开始」时清空旧结果
- 扫描完成后填充新结果

### 3.4 底部操作按钮区

从左到右排列：

1. **「打开选中文件预览」**：用系统默认应用打开所有已勾选的文件
2. **「评估选中照片质量」**：将已勾选的图片文件地址传给质量评估 Tab（仅支持 jpg/jpeg/png/bmp/tiff/webp）
3. **「删除选中(移入回收站)」**（红色按钮）：将已勾选的文件移入 Windows 回收站（非永久删除），操作前弹出确认对话框

## 四、「照片质量评估」Tab 需求

### 4.1 控制栏（顶部）

#### 4.1.1 评分尺度选择
- 下拉选择器：**严格** / **普通** / **宽松**
- 三种尺度影响评分计算阈值：
  | 参数 | 严格 | 普通 | 宽松 |
  |---|---|---|---|
  | 清晰度除数 | 1500 | 1000 | 600 |
  | 曝光容忍度 | ±30 | ±50 | ±70 |
  | 暗部扣分起始 | 3% | 5% | 10% |
  | 高光扣分起始 | 3% | 5% | 10% |
  | 噪点除数 | 120 | 200 | 350 |

#### 4.1.2 文件选择
- **「选择照片/视频」**：弹出文件选择器（多选），支持 jpg/jpeg/png/bmp/tiff/webp/mp4/mov/avi/mkv
- **「选择文件夹批量」**：弹出文件夹选择器，自动扫描文件夹内所有图片

#### 4.1.3 操作按钮
- **「📋 记忆」**：查看评估历史记录
- **「开始评估」**：启动评估线程

#### 4.1.4 进度
- 进度条实时显示评估进度

### 4.2 结果展示区（占窗口大部分，分为左右两栏）

#### 4.2.1 左侧：评分卡片列表
- 竖向滚动，每张卡片包含：
  - **文件名**（14~16号字，加粗）
  - 综合评分（18号字，颜色：≥60绿 / 40~59橙 / <40红）
  - 五维评分（14号字）：构图 / 曝光 / 清晰度 / 色彩 / 噪点
  - 建议文字（14号字）
- 卡片填充空间要充足（padx≥16, pady≥8）

#### 4.2.2 右侧：评分细则面板
- **宽度要求**：≥500px（V2.2 要求加大）
- **高度要求**：≥800px
- 显示内容：
  - 基础评分细则（五维说明 + 算法简述）
  - 当前评分尺度的具体阈值参数
- 字体适中（16号）

#### 4.2.3 评分记忆功能
- 每次评估结果自动保存到 eval_history.json
- 记录字段：时间 / 文件名 / 分辨率 / 五维评分 / 建议 / 评分尺度
- 「📋 记忆」按钮弹出历史记录对话框
- 历史对话框：表格展示 + 支持按文件名搜索 + 按时间倒序排列

## 六、质量评估算法需求（Tool 2）

### 6.1 五维评分

| 维度 | 权重 | 算法 |
|---|---|---|
| 构图 | 25% | Sobel 边缘检测 + 三分法 + 对称性 + 内容密度 |
| 曝光 | 25% | 直方图分析 + 亮度均值偏离 + 暗部/高光剪切比例 + 对比度 |
| 清晰度 | 20% | Laplacian 方差 |
| 色彩 | 15% | Hasler & Süsstrunk 色彩丰富度（饱和度分布） |
| 噪点 | 15% | 平滑区域局部方差采样 |

### 6.2 综合评分公式
```
total = sharp*0.20 + exposure*0.25 + composition*0.25 + color*0.15 + noise*0.15
```

### 6.3 降级方案
- 无 opencv 时自动降级到纯 numpy 计算

### 6.4 视频评估
- 每 2 秒采样一帧，每帧独立评分
- 最终输出 avg / min / max

## 七、非双格式文件清理算法需求（Tool 1）

### 7.1 扫描逻辑
- 遍历目标文件夹（含子目录）
- 识别所有文件，按文件名（不含扩展名）分组
- 找到「JPG/JPEG 已不存在但 RAW/PNG/TIFF/BMP 存在」的文件

### 7.2 支持的格式
- RAW：CR2/CR3/NEF/ARW/DNG/ORF/RW2 等 21 种
- 伴生格式：PNG/TIFF/BMP

### 7.3 删除策略
- 只移入 Windows 回收站（通过 Shell.Application COM 接口）
- 不直接永久删除
- 删除前弹出确认对话框
