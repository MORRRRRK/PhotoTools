# PhotoTools V5.1 — 功能说明

## 核心功能

### 1. 单一文件类型筛选
扫描已筛选的素材文件夹，自动找出「同名但 JPG 已删除」的 RAW/PNG/TIFF 文件。

- 支持 21 种 RAW 格式：CR2/CR3/NEF/ARW/DNG/ORF/RW2 等
- 支持 PNG、TIFF、BMP 格式
- 并行扫描多个文件夹
- 列表展示：文件名 / 类型 / 大小 / 来源文件夹
- 复选框全选/单选，批量移入回收站

### 2. 照片质量评估
从构图、曝光、清晰度、色彩、噪点五个维度评价照片（0~100 分），支持单张、文件夹批量、视频帧采样评估。

### 3. PushPlus 推送
- 预留评分报告推送接口

### 4. 视频代理生成
- 支持批量选择视频，生成 1080p / 2.7K / 4K 代理
- 可选 60fps / 30fps / 24fps
- 选择组合后显示单个文件和总预估大小
- 后台队列生成，显示当前文件、进度、剩余数量，支持取消
- 支持“停止生成”打断当前任务，已生成文件不受影响
- 单个失败不中断队列，可重试失败项
- 代理文件写入原片旁 `_proxies/`，原片不修改
- 代理输出目录可在设置中自定义
- 支持“打开代理文件夹”一键定位已生成代理
- 支持删除选中代理、删除全部代理，释放存储空间
- 视频预览自动优先使用代理文件

### 5. 设置
- PushPlus Token 配置
- 并行扫描数配置
- 外观模式切换
- 配置持久化到 config.json

### 6. 一键生成延时视频
- JPG 整文件夹或多选导入，按文件名自然排序
- 1080P / 2K / 4K、24/25/30/60fps
- CRF 标准/高/最高画质档位
- vidstab 两遍增稳，支持低/中/高强度
- EXIF 方向自动纠正，LANCZOS 缩放，H.264 High Profile / yuv420p / +faststart
- 高质量模式：PNG 无损临时帧、CRF 14/12/10、slow + stillimage
- 延时去闪烁 deflicker + vidstab tripod 参考帧增稳
- 进度、剩余时间、停止生成、输出校验
