## 使用流程

### 场景一：清理残留 RAW/PNG 文件

**流程：添加文件夹 → 开始扫描 → 勾选文件 → 删除**

1. 在「单一文件类型筛选」中添加已筛选过的素材文件夹
2. 点击「开始扫描」，并行扫描所有添加的文件夹
3. 列表显示「同名但 JPG 已删除」的残留文件
4. 勾选文件后，可删除选中文件，也可直接评估选中照片质量

### 场景二：评估照片质量

1. 进入「照片质量评估」
2. 选择照片/视频或选择文件夹批量
3. 点击「开始评估」，进度条实时显示进度
4. 查看综合评分、五维评分和建议

### 场景三：视频代理生成

1. 进入「视频代理」，添加视频文件或文件夹
2. 选择分辨率：1080p / 2.7K / 4K
3. 选择帧率：60fps / 30fps / 24fps
4. 界面实时显示每个文件的预估大小和总预估大小
5. 勾选视频后点击「生成代理」
6. 队列显示当前文件、进度、剩余数量，可随时取消
7. 失败项可点击「代理生成失败点击重试」；代理文件可一键删除，原片不受影响
8. 生成中可点击「停止生成」打断当前任务，已完成的代理保留
9. 点击「打开代理文件夹」可快速定位代理输出目录

### 场景四：设置

1. 进入「设置」Tab
2. 配置 PushPlus Token、并行扫描数、外观模式
3. 配置代理输出目录，留空时默认使用原片旁 `_proxies/`
4. 点击「保存设置」，配置自动保存到 config.json

### 场景五：一键生成延时视频

1. 进入「一键生成延时视频」，添加 JPG 文件或文件夹
2. 选择目标分辨率、画质档位、帧率和增稳开关
3. 选择输出文件夹，点击「生成延时视频」
4. 进度区显示当前帧、剩余时间；生成中可点击「停止生成」
5. 完成后显示输出路径、帧数、分辨率、帧率、时长和大小

## 注意事项

- 删除操作将文件移入回收站，不直接永久删除
- 代理文件存放在原片旁 `_proxies/` 目录，原片不修改、不覆盖
- 质量评估为纯算法评估，建议作为参考而非绝对标准
